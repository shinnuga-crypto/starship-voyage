# 星系航行戦艦（仮称）

区画ブロックを継ぎ足して艦を大きくしながら、星系を渡っていく Windows 向けのシューティングです（Godot 4.7.2）。

## ダウンロード

[Releases](../../releases) から `StarshipVoyage-<版>-windows.zip` をダウンロードして展開し、`Play.cmd` をダブルクリックします。初回だけ準備に少し時間がかかります。

- 戦艦・空母・要塞の3つの艦種。区画ブロックと装備を造船所で組み替える。
- 旅で集めた研究データで、研究所の武器や装備を開いていく。
- セーブは造船所と星系マップで。研究データは旅が終わっても残る。

操作と同梱物のライセンスは ZIP の `ReadMe.txt` にあります。
